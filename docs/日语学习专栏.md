# 日语学习日记：每天怎么写

专栏入口：[日语学习日记](https://catailor.github.io/topics/japanese/)。首页的快捷入口与顶部「探索」菜单都可以进入。

建议每天一篇，把当天学过的内容、词语和复习情况放在一起。文章按日期从新到旧排列，填写 `日语学习` 分类就会自动加入专栏，也能在站内搜索中搜到。现在没有替你填写任何学习经历，专栏等待第一篇正式日记。

## 1. 新建今天的日记

在项目目录运行：

```powershell
Set-Location D:\Hexo
npm run japanese
```

它会按电脑的当地日期创建 `source/_posts/japanese-YYYY-MM-DD.md`，并显示完整路径。打开这个文件，填上今天的内容即可。同一天重复运行会提示继续编辑已有文件，不会覆盖你的文字。

补写某一天：

```powershell
npm run japanese -- 2026-09-11
```

也可以使用 Hexo 原生模板命令 `npx hexo new japanese "日语学习日记 · 2026-09-11"`，但日常更推荐上面的日期命令，文件名比较整齐。

## 2. 填哪些内容

| 部分 | 写法 |
| --- | --- |
| 今天学了什么 | 学习时长、教材或课程进度、完成的小目标 |
| 今日词语 | 单词、假名读音、词性、中文意思，以及自己写的例句 |
| 语法与表达 | 用法或接续、例句、容易混淆的地方 |
| 听力／跟读／阅读 | 使用的材料、遇到的难点、理解后的记录 |
| 复习与明天 | 今天复习了什么、仍未记牢的词、下一次准备做什么 |
| 今天的一点感受 | 一两句即可，忙的时候也可以只记录几个词 |

不必每天填满全部栏目，可以删掉当天没用到的部分。相同单词再次出现时，可以在复习部分记录“又忘了哪里”或“这次能怎么用了”，比重复抄整张表更便于回顾。

文章最上方有这些设置：

```yaml
layout: post
title: 日语学习日记 · 2026-09-11
date: 2026-09-11 12:00:00
description: 用一句话概括今天真正学了什么。
categories:
  - 日语学习
tags:
  - 日语
  - 学习日记
topic: 日语学习
symbol: あ
```

- `title` 可加当天主题，如“日语学习日记 · 2026-09-11｜今天的动词”。
- `description` 改成当天的小摘要，会显示在首页、文章导读和专栏列表。
- **保留 `categories` 下的 `日语学习`**，就能自动归入专栏，无须手动修改文章清单。
- 标签可按需要增加，例如“单词”“语法”“听力”。这些标签同样可以搜索和点击浏览。
- 不必再为每篇日记编辑 `moonlit.yml`；已有的字数、阅读时间、目录和阅读位置记录会自动生效。日文假名也计入字数。

## 3. 预览与发布

填完再预览：

```powershell
npm run server
```

打开本机博客检查表格、文字和例句。停止预览后构建，确认无误再发布。以下文件名换成当天生成的实际文件名：

```powershell
npm run build
git add source/_posts/japanese-2026-09-11.md
git commit -m "Add Japanese study diary"
git push origin main
```

这里只会提交你指定的这篇日记。未填写的模板先不要发布；如果需要暂存草稿，可移到 `source/_drafts/`，正式写好后再发布。日语专栏属于公开内容。

## 专栏设置在哪里

`source/_data/notebook.yml` 中的这段控制专栏标题、介绍和排序：

```yaml
- id: japanese
  title: 日语学习日记
  description: 每天一点日本語。记录今天的学习、遇见的词语，以及慢慢积累的进步。
  category: 日语学习
  order: newest
```

`newest` 表示最新在前，`oldest` 表示最早在前。修改模板请编辑 `scaffolds/japanese.md`，它只影响之后新建的日记，已有文章不会被改动。
