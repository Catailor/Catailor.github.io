# 日语学习专栏

入口：[日语学习日记](https://catailor.github.io/topics/japanese/)。导航中的「日语日记」和首页专栏区域都可以进入。[我的词语本](https://catailor.github.io/words/)用于查词和复习。

## 每天怎么写

双击项目根目录的「打开写作台.cmd」，选择日期，点击「日语速记」或「完整日记」。填写标题与正文，右侧看预览；草稿会自动保存到本机。

简版保留「今天学了什么、今日词语、下次复习什么」三部分；完整版还包含语法、听读与学习感受。没有内容的项目可以删除。

点击「添加词语」填表即可，不必手写 Markdown 表格。准备好后点击「预览发布」，核对内容，再确认发布。其他草稿不会一起上传。完整步骤见 [写作台使用说明](写作台使用说明.md)。

## 直接编辑文件

在项目目录运行 npm run japanese，会按当地日期创建 source/_drafts/japanese-YYYY-MM-DD.md。指定日期可运行 npm run japanese -- 2026-09-11。同一天重复新建不会覆盖原文；若已有公开文章，则继续编辑原文件。

编辑完成后，可回写作台预览并发布。不要将未完成模板直接移进 _posts 后批量上传。

## 词语本如何收集

词语表保留「单词、读音（假名）、词性、中文意思、例句与用法」表头。填了单词和中文意思的行会在发布后进入词语本。

相同单词和假名只显示一次，保留不同释义和记录日期。支持按日语、假名、中文查找，标记待复习，遮住释义自测。复习标记保存在当前浏览器中。

## 设置位置

- source/_data/notebook.yml 中 japanese 专题按「日语学习」分类自动收集文章，newest 表示最新在前。
- 专栏按月浏览，每页最多 20 篇，日记末尾只展示相邻篇与专栏入口。
- 简版模板：scaffolds/japanese.md；完整版模板：scaffolds/japanese-full.md。
- 修改模板只影响以后新建的日记，不会改写旧文章。
