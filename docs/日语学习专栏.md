# 每天写一篇日语学习记录

1. 打开写作台，左侧进入「日语学习日记」系列。
2. 点「在这里写一篇」，直接记录今天学了什么。想要现成表格，就点「新建文章」旁的下拉按钮，选「日语学习 · 简记」或「日语学习 · 整理」。
3. 写好后点「发布」→「确认发布」。不发布就一直是本机草稿。

在系列内新建的文章会自动加入系列。一天可以写多篇；日期自动填好，也可以在「文章设置」里修改。

词语表用「单词」「读音（假名）」「中文意思」「例句与用法」这些表头。在表格里直接输入，右键增删行列。填了单词和中文意思的行，发布后会汇总到[我的词语本](https://catailor.github.io/words/)。重复的单词和假名会合并，保留释义与来源日期。

想改变日记结构，在「管理模板」里修改即可；也可以写好一篇框架后，点「文章设置」→「将这篇存为模板」。旧文章不受影响。

系列可以改名、写简介、拖动排序，也可以把已经写好的文章批量加进来。详细操作见[写作台使用说明](写作台使用说明.md)。
