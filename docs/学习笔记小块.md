# 提示、例句、易错点和参考资料

在写作台切换到「Markdown 编辑」，复制以下任意一段，换成自己的内容。发布后会自动使用对应样式。编辑时保留普通引用格式。

```markdown
> [!提示]
> 把今天最重要的一点写在这里。

> [!例句]
> 毎日、日本語を勉強しています。
>
> 我每天都在学习日语。

> [!易错点]
> 这里写容易混淆的词语或语法区别。

> [!参考资料]
> [资料名称](https://example.com/)
```

每行开头保留 `>`，不同小块之间空一行。里面可以正常使用加粗、列表和链接。

也支持英文标记 `[!TIP]`、`[!EXAMPLE]`、`[!WARNING]`、`[!REFERENCE]`。普通引用不会改变样式；代码块里的示例不会被转换。
