# 写作台：记住这几件事就够了

**打开：点桌面或开始菜单里的「月下手记写作台」图标。** 它会在后台启动本机服务，并用独立的应用窗口打开写作台（没有地址栏和黑色命令行窗口）。

第一次使用（或项目文件夹搬家后）先在项目里运行一次 `npm run studio:shortcut` 生成图标；想固定到任务栏，在开始菜单里右键它 →「固定到任务栏」。`git pull` 之后直接点图标即可：需要时会自动安装新组件、换上新版服务。旧的「打开写作台.cmd」和 `npm run studio` 仍然可以用。

## 写文章

1. 打开写作台先看到「书桌」，有四张卡片：**写一篇文章**、**记一条碎碎念**、**今天的日语日记**、**从模板开始**。上次没写完的文章会显示「继续写」。
2. 直接写标题和正文，标题还没想好也能保存。停下输入约一秒，看到「已保存到本机」就保存好了。
3. 想给别人看时，点右上角「发布」→「确认发布」。确认页会给出几条「发布前看一眼」的小建议（例如还没写摘要），只是提醒，不影响发布。底部显示「已上线」才表示网站更新完成。

打开文章后只剩一张稿纸。左上角「← 书桌」回到书桌；旁边的列表图标（Ctrl+Shift+B）在不离开稿纸的情况下快速切换文章，点空白处或按 Esc 收起。有多个小标题时，右上角会出现「目录」图标。下次打开会回到上次的文章和阅读位置。

**找东西、做操作都可以按 Ctrl+K**：输入文章标题直接打开，或输入「新建」「源码」「历史」「快捷键」等命令名，回车执行。

**深浅色跟随时间**：06:00–18:00 浅色，其余时间深色。左下角可以手动切换，手动选择会保持到下一次 06:00 或 18:00，之后又自动跟随时间。

### 排版和源码（像 Typora）

平时直接在排版里写：输入 `## ` 变成小标题，`- ` 变成列表，`> ` 变成引用，`$x^2$` 变成公式。选中文字会出现小工具栏（加粗、斜体、链接、注音等）。

想看或改原文时，点右上角 `</>` 或按 **Ctrl+/** 切到 Markdown 源码，再按一次切回来，光标会停在大致相同的位置。写作台只改动你编辑过的段落，其余原文（空行、表格写法、HTML 等）保持原样。

### 日语笔记小工具

- **插入菜单：** 在空行输入 `/` 打开插入菜单（标题、列表、表格、公式、图片……）。日语输入法开着也行：直接按 `/` 键打出的「・」或「／」会自动当作 `/`。
- **生词表：** 插入菜单 →「日语笔记」→「生词表」，插入「单词 / 读音 / 词性 / 中文意思 / 例句与用法」表格。
- **注音（振り仮名）：** 选中汉字点工具栏「注音」，或在插入菜单选「注音」，填写读音即可。原文写法是 `[漢字]{かんじ}`，博客上显示为汉字上方的小字假名。点已有注音可以修改读音。

### 文章属性

点右上角的面板图标（Ctrl+,）在右侧打开「文章属性」，宽屏下会一直停在旁边，下次打开文章时保持开关状态：

- **基本**：日期；**类型**（学习 / 日常 / 碎碎念，选「自动」时按分类决定）；**主题**（卡片上的小栏目名，例如「数学基础」）。
- **整理**：分类、标签、所属系列。
- **链接与摘要**：**链接名**决定文章地址，例如填 `japanese-day-1` 地址就是 `/2026/04/05/japanese-day-1/`，下面会实时显示完整地址；点旁边的魔杖按钮自动建议一个。只能用小写英文、数字和短横线，输入空格会自动变成短横线。已发布的文章改了链接名，旧地址会自动跳转到新地址。**摘要**会显示字数，留空会自动截取正文。

### 快捷键

在书桌按 **Ctrl+/**，或在 Ctrl+K 里输入「快捷键」查看全部快捷键。

| 快捷键 | 作用 |
| --- | --- |
| Ctrl+K | 搜索文章和命令 |
| Ctrl+S | 立即保存 |
| Ctrl+/ | 切换排版 / Markdown 源码（在书桌上是快捷键一览） |
| Ctrl+, | 打开或关闭文章属性 |
| Ctrl+Alt+N | 新建文章 |
| Ctrl+Shift+B | 快速切换文章 |
| Esc | 收起菜单、文章列表或面板 |

## 整理成系列

- **先建系列再写：** 左侧「我的系列」旁点「＋」，填名称；进入系列后点「新建文章」，文章自动加入。
- **先写再整理：** 在文章列表勾选几篇，点「加入系列」。可以选已有系列，也可以现场新建。
- **调整顺序：** 手动加入的文章可以拖动，或点文章旁「管理」→「上移一篇／下移一篇」。自动收集的文章按日期排序；想单独排序，先点「加入手动排序」。
- **改名、写简介、收藏：** 点系列标题旁的「设置」。收藏的系列排在侧栏前面。
- **移出系列：** 点文章旁「管理」→「移出当前系列」。文章仍在「全部文章」中。
- **更新博客上的目录：** 点「更新线上目录」。只发布系列信息，草稿正文不会发布。新系列至少发布一篇文章后才出现在博客中。

一篇文章可以加入多个系列。整理后提示条里的「撤销」可以撤回最近一次系列或模板操作；如果之后又做了其他整理，会提示你手动调整，避免覆盖。带撤销的提示 8 秒后自动收起，普通提示 5 秒后收起；鼠标停留或键盘焦点在提示内时暂停计时。

文章发布时，也会同步系列信息。确认页面会逐项列出这次的系列改名、成员、顺序和解散等变更，确认后才上传。

## 分类、标签和自动整理

- **改一篇：** 打开文章 →「文章属性」→ 填分类和标签。已有名称可以直接点选，也能输入新名称；多个名称用逗号分隔。旧的层级分类显示成「学习 / 日语」，修改正文不会打乱它。
- **查找和批量整理：** 书桌文章列表点「筛选」→ 选择条件 →「全选结果」→「分类／标签」。可追加、替换或移除名称，完成后提示条里可以撤销。
- **把旧文章整理进系列：** 筛选出想要的文章 →「全选结果」→「加入系列」。这是一次性加入，不会改分类或标签。
- **以后写起来更省事：** 系列标题旁「设置」→「新文章默认设置」，填默认分类和标签。以后在该系列内新建就会自动带上；已有文章不会被改动。
- **自动收集：** 同一个设置里展开「自动收集文章」，选择持续收集，填写分类或标签条件，再选任意匹配／全部匹配和日期顺序。页面会预览匹配数量。手动移出的文章不会自动回来，重新「加入系列」即可恢复。

例如「日语学习日记」可设置默认分类「学习」、默认标签「日语」；自动收集条件设为标签「日语」。也可以只设默认值，继续手动整理。

**保存后先在写作台生效，发布文章后才更新网页的分类、标签及专题。** 批量整理过的已发布文章，需要分别发布更新。「更新线上目录」只更新系列，使用文章已发布的分类和标签，不会提前发布其他文章的本机修改或草稿。

## 删除、恢复和撤回

- **删除草稿：** 打开文章 → 右上角「···」→「移到回收站」；也可以勾选多篇后点「删除」。
- **恢复文章：** 左侧「回收站」→ 文章旁「管理」→「恢复文章」。原来的系列还在时，也会恢复系列位置。回收站保存在本机，不会公开。
- **撤回已发布文章：** 打开文章 → 右上角「···」→「撤回为草稿」→「确认撤回」。等底部确认网站更新后，文章才真正下线；正文仍在草稿里，之后可以再发布。撤回时会移除线上的系列及相关文章引用。
- 完全没写过的新空白页会复用；切换到其他文章或回到书桌时会收掉。只要写过正文，即使没有标题，也会保留。

## 高频操作

| 想做什么 | 怎么操作 |
| --- | --- |
| 加粗、小标题、列表、链接 | 选中文字用浮动小工具栏，或空行输入 `/` 选择；加粗也可按 Ctrl+B |
| 换行、继续列表 | 按回车；空列表项再按回车即可结束列表 |
| 插入表格 | 空行输入 `/` →「表格」；鼠标移到表格边缘可以增删、拖动行列 |
| 插入图片 | 粘贴、拖入正文，或输入 `/` →「图片」选择文件；较大的 JPG、PNG 会自动缩小压缩；原图最多 20 MB，处理后最多 5 MB，GIF 保留动画 |
| 切换原文与排版编辑 | 右上角 `</>` 或 Ctrl+/ |
| 修改分类、标签、日期、类型、主题、链接名、摘要或所属系列 | 点「文章属性」（Ctrl+,），摘要不填会自动摘取正文 |
| 记一句话 | 写作台首页「记一条碎碎念」，类型自动设为碎碎念，发布后出现在博客首页右侧和「碎碎念」页 |
| 重命名文章 | 直接修改正文上方的标题，不会改变文章链接；想换地址请改「链接名」 |
| 撤销、立即保存 | Ctrl+Z、Ctrl+S |
| 复用常写的结构 | 左下角「文章模板」，选择模板 |
| 制作自己的模板 | 写好框架后，右上角「···」→「将这篇存为模板」 |
| 修改、收藏或删除模板 | 左下角「文章模板」；不影响已经写好的文章 |

日语学习只是可选模板之一，不需要每次先选文章类型。公式、换行、带说明的图片都能直接在排版里显示和编辑；只有排版编辑器无法表达的少数写法（如原始 HTML 块、引用式链接定义）会保持原文不动，并在正文上方提示。

## 常用的新入口

| 想做什么 | 在哪里操作 |
| --- | --- |
| 找回改动前的文章 | 右上角「···」→ 历史版本，选择时间，左右对照并查看高亮的改动后恢复；恢复前的内容也会保留 |
| 看上线后的排版 | 右上角眼睛图标「查看发布效果」，使用与网站相同的渲染规则和正文样式 |
| 修改图片说明或替换图片 | 右上角「···」→ 文章配图，改完后统一点「保存配图修改」；图片说明会显示在图片下方 |
| 查找、新建系列 | 正文上方「加入系列」，输入名称搜索；找不到可直接新建 |
| 选择首页展示的系列 | 系列设置 → 首页展示，选择展示最近三篇并填写顺序，再点「更新线上目录」 |
| 查看发布是否成功 | 书桌左下角「发布记录」，成功后可打开线上文章，失败后可重新检查并发布 |

历史版本恢复标题、摘要和正文，保留当前文章链接、日期、分类及系列设置，不会自动发布。能明确对应到文章的旧备份会自动加入历史；无法确定归属的旧备份仍保留在本机。

## 保存、发布和私人手记

**保存只保存到这台电脑；发布才更新博客。** 发布期间可以继续写，后面的修改留到下次发布。其他草稿和其他文章未发布的正文不会跟着上传。

私人内容从左下角「私人手记」进入，用原密码解锁。写完点「加密保存到本机项目」，再点上方「发布加密手记」。私人内容只保存密文，不要把它放进普通文章或普通模板。

草稿、自定义模板和系列收藏保存在本机，换电脑不会自动带过去。换电脑前请保留整个项目文件夹，包括隐藏的 `.studio`、`.studio-backups`、`.private-backups` 和草稿目录。私人手记也可在解锁后导出加密备份。

遇到「另一个窗口修改了文章」时，先复制当前文字；重新打开后，写作台会提供保留未保存内容为另一篇草稿的入口，避免互相覆盖。
