# 写作台：记住这几件事就够了

**打开：双击项目里的「打开写作台.cmd」。** 更新后请重新双击打开，启动入口会自动选择新版服务。

## 写文章

1. 点「新建文章」，直接写标题和正文。标题还没想好也能保存。
2. 停下输入约一秒，看到「已保存到本机」就保存好了。
3. 想给别人看时，点右上角「发布」→「确认发布」。底部显示「已上线」才表示网站更新完成。

进入文章后，资料库默认收起。点左上角「资料库」可以展开，在同一位置再点收起；也可以按 Ctrl+Shift+B。正文两侧留白也可以滚动文章。有多个小标题时，右上角会出现「目录」，用来快速跳转。

下次打开会回到上次的文章和阅读位置。「最近写过」按文件最后修改时间排序，并显示修改时间；不依赖浏览器里的打开记录。只打开而没修改的文章不会排到最前。

## 整理成系列

- **先建系列再写：** 左侧「我的系列」旁点「＋」，填名称；进入系列后点「新建文章」，文章自动加入。
- **先写再整理：** 在文章列表勾选几篇，点「加入系列」。可以选已有系列，也可以现场新建。
- **调整顺序：** 手动加入的文章可以拖动，或点文章旁「管理」→「上移一篇／下移一篇」。自动收集的文章按日期排序；想单独排序，先点「加入手动排序」。
- **改名、写简介、收藏：** 点系列标题旁的「设置」。收藏的系列排在侧栏前面。
- **移出系列：** 点文章旁「管理」→「移出当前系列」。文章仍在「全部文章」中。
- **更新博客上的目录：** 点「更新线上目录」。只发布系列信息，草稿正文不会发布。新系列至少发布一篇文章后才出现在博客中。

一篇文章可以加入多个系列。整理后提示条里的「撤销」可以撤回最近一次系列或模板操作；如果之后又做了其他整理，会提示你手动调整，避免覆盖。带撤销的提示 8 秒后自动收起，普通提示 5 秒后收起；鼠标停留或键盘焦点在提示内时暂停计时。

文章发布时，也会同步系列信息。确认页面会逐项列出这次的系列改名、成员、顺序和解散等变更，确认后才上传。

## 分类、标签和自动整理

- **改一篇：** 打开文章 →「文章设置」→ 填分类和标签。已有名称可以直接点选，也能输入新名称；多个名称用逗号分隔。旧的层级分类显示成「学习 / 日语」，修改正文不会打乱它。
- **查找和批量整理：** 资料库点「按分类、标签筛选」→ 选择条件 →「全选结果」→「分类／标签」。可追加、替换或移除名称，完成后提示条里可以撤销。
- **把旧文章整理进系列：** 筛选出想要的文章 →「全选结果」→「加入系列」。这是一次性加入，不会改分类或标签。
- **以后写起来更省事：** 系列标题旁「设置」→「新文章默认设置」，填默认分类和标签。以后在该系列内新建就会自动带上；已有文章不会被改动。
- **自动收集：** 同一个设置里展开「自动收集文章」，选择持续收集，填写分类或标签条件，再选任意匹配／全部匹配和日期顺序。页面会预览匹配数量。手动移出的文章不会自动回来，重新「加入系列」即可恢复。

例如「日语学习日记」可设置默认分类「学习」、默认标签「日语」；自动收集条件设为标签「日语」。也可以只设默认值，继续手动整理。

**保存后先在写作台生效，发布文章后才更新网页的分类、标签及专题。** 批量整理过的已发布文章，需要分别发布更新。「更新线上目录」只更新系列，使用文章已发布的分类和标签，不会提前发布其他文章的本机修改或草稿。

## 删除、恢复和撤回

- **删除草稿：** 打开文章 →「文章设置」→「移到回收站」；也可以勾选多篇后点「删除」。
- **恢复文章：** 左侧「回收站」→ 文章旁「管理」→「恢复文章」。原来的系列还在时，也会恢复系列位置。回收站保存在本机，不会公开。
- **撤回已发布文章：** 打开文章 →「文章设置」→「撤回为草稿」→「确认撤回」。等底部确认网站更新后，文章才真正下线；正文仍在草稿里，之后可以再发布。撤回时会移除线上的系列及相关文章引用。
- 完全没写过的新空白页会复用；切换到其他文章或资料库时会收掉。只要写过正文，即使没有标题，也会保留。

## 高频操作

| 想做什么 | 怎么操作 |
| --- | --- |
| 加粗、小标题、列表、链接 | 用正文上方的小工具栏；加粗也可按 Ctrl+B |
| 换行、继续列表 | 按回车；空列表项再按回车即可结束列表 |
| 插入表格 | 工具栏点表格图标；在表格里右键可以增删行列 |
| 插入图片 | 粘贴、拖入正文，或点图片图标选择文件；较大的 JPG、PNG 会自动缩小压缩；原图最多 20 MB，处理后最多 5 MB，GIF 保留动画 |
| 切换原文与排版编辑 | 右上角「Markdown 编辑」查看和编辑原文，再点「排版编辑」切回来 |
| 修改分类、标签、日期、摘要或所属系列 | 点「文章设置」，摘要不填会自动摘取正文 |
| 重命名文章 | 直接修改正文上方的标题，不会改变文章链接 |
| 撤销、立即保存 | Ctrl+Z、Ctrl+S |
| 复用常写的结构 | 左下角「文章模板」，选择模板 |
| 制作自己的模板 | 写好框架后，在「文章设置」里点「将这篇存为模板」 |
| 修改、收藏或删除模板 | 左下角「文章模板」；不影响已经写好的文章 |

日语学习只是可选模板之一，不需要每次先选文章类型。普通文章始终可以在排版和 Markdown 之间切换；公式等特殊内容单独显示排版，点「编辑这一块」修改原文，完成后恢复排版。

## 常用的新入口

| 想做什么 | 在哪里操作 |
| --- | --- |
| 找回改动前的文章 | 文章设置 → 历史版本，选择时间，左右对照后恢复；恢复前的内容也会保留 |
| 看上线后的排版 | 文章设置 → 查看发布效果，使用与网站相同的渲染规则和正文样式 |
| 修改图片说明或替换图片 | 文章设置 → 文章配图；图片说明会显示在图片下方 |
| 查找、新建系列 | 正文上方「加入系列」，输入名称搜索；找不到可直接新建 |
| 选择首页展示的系列 | 系列设置 → 首页展示，选择展示最近三篇并填写顺序，再点「更新线上目录」 |
| 查看发布是否成功 | 资料库左下角「发布记录」，成功后可打开线上文章，失败后可重新检查并发布 |

历史版本恢复标题、摘要和正文，保留当前文章链接、日期、分类及系列设置，不会自动发布。能明确对应到文章的旧备份会自动加入历史；无法确定归属的旧备份仍保留在本机。

## 保存、发布和私人手记

**保存只保存到这台电脑；发布才更新博客。** 发布期间可以继续写，后面的修改留到下次发布。其他草稿和其他文章未发布的正文不会跟着上传。

私人内容从左下角「私人手记」进入，用原密码解锁。写完点「加密保存到本机项目」，再点上方「发布加密手记」。私人内容只保存密文，不要把它放进普通文章或普通模板。

草稿、自定义模板和系列收藏保存在本机，换电脑不会自动带过去。换电脑前请保留整个项目文件夹，包括隐藏的 `.studio`、`.studio-backups`、`.private-backups` 和草稿目录。私人手记也可在解锁后导出加密备份。

遇到「另一个窗口修改了文章」时，先复制当前文字；重新打开后，写作台会提供保留未保存内容为另一篇草稿的入口，避免互相覆盖。

安装 Node.js、Git 和 PowerShell 7，在项目中运行一次 `npm ci`，配置此仓库的 GitHub 推送权限。之后双击「打开写作台.cmd」即可。写作台通常使用 `http://127.0.0.1:4003/`；旧服务仍在运行时会自动选用其他本机端口。只在本机运行，不是公开网站的后台登录页。
