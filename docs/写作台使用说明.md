# 写作台使用说明

## 打开写作台

双击项目根目录的 `打开写作台.cmd`，浏览器会打开本机写作台。也可以在项目目录执行 `npm run studio`，访问 `http://127.0.0.1:4003/`。

首次在新电脑使用，需要安装 Node.js、Git、PowerShell 7，运行一次 `npm ci`，并配置好该仓库的 GitHub 推送权限。本机写作台不会部署到公开网站。

## 每天写日语日记

1. 选择日期，点击「日语速记」。详细整理语法、听读和复习计划时，选「完整日记」。同一天已有日记时会打开原文。
2. 填标题和正文。标题可以突出主题，例如「は 和 が：今天终于分清一点」。摘要可留空。
3. 点击「添加词语」，填单词、假名、词性、中文意思和例句。会自动插入日记的词语表，不必手写表格。
4. 停止输入约一秒后自动保存。看到「已保存到本机」即可放心继续；右侧同步显示正文预览，支持常用 Markdown 和数学公式。
5. 点击「预览发布」，核对标题、摘要、专栏和随文图片，再点击「确认发布」。

简版只有学习内容、词语和下次复习三部分。完整版的空项目可以填写，也可以删除；发布前会拦住空正文和未填写的模板项目。图片通过「插入图片」选择，支持 PNG、JPG、WebP、GIF，单张不超过 5 MB。

## 保存和上线的区别

| 状态 | 含义 |
| --- | --- |
| 已保存到本机 | 文件在当前电脑中，尚未更新博客 |
| 正在检查／上传 | 在隔离目录生成网站，只提交所选文章及引用的上传图片 |
| 已上传，等待网站更新 | GitHub 已接收提交，部署仍在进行 |
| 已上线 | 已从公开网站确认本次发布标记 |
| 失败／尚未确认上线 | 阅读提示，必要时查看部署记录；等待状态不会被当作成功 |

新文章默认放在 `source/_drafts/`，该目录被 Git 忽略，也不会进入普通网站构建。发布成功后，所选草稿转为 `source/_posts/` 中的文章。其他草稿、未提交文件和其他文章的本机修改不会一起上传。

已有文章可以从左侧打开编辑。自动保存只更新本机版本，仍要发布才更新网站。发布前需要本机 main 与远程 main 一致；如果还有未完成的暂存操作或远程更新，先完成同步。

同时在两个窗口编辑同一篇文章时，旧窗口的保存会被拒绝。请先复制需要保留的文字，再重新打开文章。普通文章的历史内容保存在 `.studio-backups/`，不上传到 GitHub。

## 私人手记

点击顶部「私人手记」进入独立加密编辑页，用原密码解锁。

- 编辑时有实时预览；停下输入后，草稿会加密后保存在当前浏览器中。
- 重新解锁时发现草稿，会询问是否继续编辑。换浏览器、清除站点数据后不会保留这份浏览器草稿。
- 点击「加密保存到本机项目」才会更新项目密文。之后回到写作台，点击「发布私人手记」。
- 「从本机加密备份恢复」可按时间选择备份。恢复会替换整个手记本，当前版本会先另存为加密备份。备份使用旧密码时，需要输入对应密码。
- 不要把私人正文或附件写进普通草稿。普通草稿的本机备份是明文，私人草稿与私人备份才是密文。

写作台的私人编辑入口默认使用本机端口 4006；单独执行 `npm run private` 仍使用 4002。浏览器加密草稿按访问地址分别保存，请固定使用同一个入口。

## 专栏与词语本

日语专栏按月浏览，每页最多 20 篇。日记末尾显示相邻文章和专栏入口。首页只展示最近三篇日语记录，其他学习文章保持独立列表。

日语日记中的词语表在发布后自动汇总到 `/words/`。同一单词和假名会合并，保留不同释义与记录日期。可以搜索日语、假名、中文，标记「还没记牢」，或遮住释义回想。复习标记保存在当前浏览器，不跨设备同步。

## 个性文案和外观

首页「最近在学」「接下来想做」位于 `source/_data/notebook.yml` 的 `now.learning` 和 `now.goal`。介绍、友链、碎碎念也在该文件中。修改站点设置后，按原项目发布流程提交配置文件；文章发布按钮不会顺带发布配置修改。

少于 300 字且没有章节标题的文章使用紧凑短记版式。长文保留目录与可展开的阅读设置，只显示顶部细进度条。指定插画的文章展示图片，其他文章采用文字列表，不再自动生成几何封面。
