数学笔记：线性代数与概率

协方差矩阵：决定了数据的形状，通常是椭圆
相关系数：排除单位影响，描述是否有线性关系

内积：降维压缩，行 ×\times× 列
外积：升维展开，列 ×\times× 行，但秩仍然是1

随机变量X：一维的，一个数
随机向量X：n维的
协方差Cov(x, y)都是一维的，描述线性相关性，是一个数，Cov(X)多维，描绘形状，方差是一维的X的协方差，而且由于是一维就是一个数
协方差矩阵包含了方差和协方差

xTSWx\mathbf{x}^T S_W \mathbf{x}xTSW​x 无论SWS_WSW​是什么矩阵，都可以另类看做x的平方

对角化：QTCQ=ΛQ^T C Q = \LambdaQTCQ=Λ，QQQ是新的坐标系，要乘的也是在新的坐标系下的向量，一定是实对称矩阵
- 一般情形是相似变换，即 P−1CP=ΛP^{-1} C P = \LambdaP−1CP=Λ
- 由于是对称的，得到的QQQ一定是正定的，所以Q−1=QTQ^{-1} = Q^TQ−1=QT
- 如果是正定矩阵：那么得到的PPP一定是正定的，则记作QQQ

能通过 Cholesky 分解找到 GGG 使得 Q=GGTQ = GG^TQ=GGT 且 GGG 是正交矩阵
实对称 ⇒ 正交对角化；正定 ⇒ 特征值全正；Cholesky ⇒ (C=GG^T)，不是 (Q=GG^T)。

合同变换：PTAPP^T A PPTAP，正负特征值数量不变，一定是实对称矩阵
- 正定矩阵合同变换后任正定
- 正定矩阵能通过合同变换变为单位矩阵
- 合同变换和相似变换都是变换坐标系，本质一样

MLE：最大似然估计：
1. 写出似然函数
2. 取对数
3. 求导，令导数为0
4. 求解

PDF：概率密度函数，积分为1
如果 y 是类别随机变量，那么 p(x∣y) 作为条件分布时是合法条件概率；但当我们固定观测数据 x ，把它看成关于 y 或 θ 的函数时，它就是似然，不一定是概率分布。后验 p(y∣x) 则是固定数据后关于类别 y 的概率分布。

后验∝似然×先验\text{后验} \propto \text{似然} \times \text{先验}后验∝似然×先验
似然是在评价“解释能不能产生现象”；后验是在评价“看到现象后解释有多可信”。

贝叶斯公式就是把“似然”变成“后验

线性代数总结：实对称矩阵、相似变换、对角化、秩

1. 实对称矩阵

实对称矩阵满足：

AT=A A^T=A AT=A

核心性质：

实对称矩阵一定可以正交对角化 \boxed{\text{实对称矩阵一定可以正交对角化}} 实对称矩阵一定可以正交对角化​

即：

QTAQ=Λ Q^TAQ=\Lambda QTAQ=Λ

其中：

  • QQQ：由单位正交特征向量组成
  • Λ\LambdaΛ：由特征值组成的对角矩阵
  • 因为 QQQ 是正交矩阵，所以：

Q−1=QT Q^{-1}=Q^T Q−1=QT

注意：

AT=A A^T=A AT=A

不代表：

A−1=AT A^{-1}=A^T A−1=AT

只有正交矩阵才满足：

Q−1=QT Q^{-1}=Q^T Q−1=QT

2. 相似变换

相似变换形式：

B=P−1AP B=P^{-1}AP B=P−1AP

含义：

同一个线性变换在不同坐标系下的表示 \boxed{\text{同一个线性变换在不同坐标系下的表示}} 同一个线性变换在不同坐标系下的表示​

如果 AAA 和 BBB 相似，那么它们有相同的：

  • 特征值
  • 行列式
  • 迹
  • 秩

但特征向量会因为换坐标系而改变表示。

3. 对角化

如果存在可逆矩阵 PPP，使得：

P−1AP=D P^{-1}AP=D P−1AP=D

其中 DDD 是对角矩阵，那么 AAA 可对角化。

对角化步骤

  1. 求特征值：

det⁡(A−λI)=0 \det(A-\lambda I)=0 det(A−λI)=0

  1. 求特征向量：

(A−λI)x=0 (A-\lambda I)x=0 (A−λI)x=0

  1. 把特征向量作为列组成矩阵：

P=(p1,p2,…,pn) P=(p_1,p_2,\dots,p_n) P=(p1​,p2​,…,pn​)

  1. 对应特征值组成对角矩阵：

D=diag⁡(λ1,λ2,…,λn) D=\operatorname{diag}(\lambda_1,\lambda_2,\dots,\lambda_n) D=diag(λ1​,λ2​,…,λn​)

于是：

P−1AP=D P^{-1}AP=D P−1AP=D

4. 能不能对角化怎么看？

对于 n×nn\times nn×n 矩阵：

A 可对角化⟺A 有 n 个线性无关特征向量 \boxed{ A\text{ 可对角化} \Longleftrightarrow A\text{ 有 }n\text{ 个线性无关特征向量} } A 可对角化⟺A 有 n 个线性无关特征向量​

也就是：

特征向量组成的 P 满秩 \boxed{ \text{特征向量组成的 }P\text{ 满秩} } 特征向量组成的 P 满秩​

注意：不是看 AAA 本身是否满秩。

常见判断

如果 AAA 有 nnn 个不同特征值，则一定可对角化。

如果特征值重复，要看：

几何重数=代数重数 \boxed{ \text{几何重数}=\text{代数重数} } 几何重数=代数重数​

其中：

  • 代数重数：特征值在特征多项式中出现的次数
  • 几何重数：对应特征空间的维数，也就是线性无关特征向量个数

5. 线性无关特征向量方向

两个向量线性无关，就是它们不是倍数关系。

例如：

(10),(01) \begin{pmatrix} 1\\ 0 \end{pmatrix}, \quad \begin{pmatrix} 0\\ 1 \end{pmatrix} (10​),(01​)

线性无关。

但：

(10),(30) \begin{pmatrix} 1\\ 0 \end{pmatrix}, \quad \begin{pmatrix} 3\\ 0 \end{pmatrix} (10​),(30​)

线性相关，因为第二个是第一个的 3 倍。

所以“只有一个特征向量方向”指的是所有特征向量都在同一条直线上。

6. 解 Ax=0Ax=0Ax=0

这是齐次线性方程组。

解法

  1. 对 AAA 做行化简
  2. 找主元列和自由变量
  3. 用自由变量表示主元变量
  4. 写成参数向量形式

例如：

(0100)x=0 \begin{pmatrix} 0&1\\ 0&0 \end{pmatrix} x=0 (00​10​)x=0

对应：

x2=0 x_2=0 x2​=0

所以：

x1=t x_1=t x1​=t

因此：

x=(t0)=t(10) x= \begin{pmatrix} t\\ 0 \end{pmatrix} = t \begin{pmatrix} 1\\ 0 \end{pmatrix} x=(t0​)=t(10​)

这里第 2 列有主元，第 1 列没有主元。

7. 解 Ax=bAx=bAx=b

这是非齐次线性方程组。

使用增广矩阵：

(A∣b) (A|b) (A∣b)

然后行化简。

三种情况

情况 判断
无解 出现 0=c, c≠00=c,\ c\neq 00=c, c=0
唯一解 没矛盾，且每个未知数都有主元
无穷多解 没矛盾，但有自由变量

通解形式：

x=xp+xh \boxed{ x=x_p+x_h } x=xp​+xh​​

其中：

  • xpx_pxp​：一个特解，满足 Axp=bAx_p=bAxp​=b
  • xhx_hxh​：齐次解，满足 Axh=0Ax_h=0Axh​=0

8. 秩

矩阵的秩记作：

rank⁡(A) \operatorname{rank}(A) rank(A)

表示矩阵中线性无关行或列的个数。

求秩方法：

行化简后，数非零行数 \boxed{\text{行化简后，数非零行数}} 行化简后，数非零行数​

也等于：

主元个数 \boxed{\text{主元个数}} 主元个数​

满秩指：

rank⁡(A)=min⁡(m,n) \operatorname{rank}(A)=\min(m,n) rank(A)=min(m,n)

对于 n×nn\times nn×n 方阵：

det⁡(A)≠0⟺rank⁡(A)=n \det(A)\neq0 \Longleftrightarrow \operatorname{rank}(A)=n det(A)=0⟺rank(A)=n

9. 线性变换的几何理解

线性变换不只是旋转和拉伸，还包括：

  • 旋转
  • 拉伸 / 压缩
  • 反射
  • 剪切
  • 投影

线性变换可以理解为：

保持原点和直线结构的空间变形 \boxed{ \text{保持原点和直线结构的空间变形} } 保持原点和直线结构的空间变形​

10. 可对角化矩阵与实对称矩阵的区别

一般可对角化矩阵：

P−1AP=D P^{-1}AP=D P−1AP=D

含义：

在某个特征向量坐标系下是纯伸缩 \boxed{ \text{在某个特征向量坐标系下是纯伸缩} } 在某个特征向量坐标系下是纯伸缩​

但这个坐标系可能是斜坐标系。

实对称矩阵：

QTAQ=Λ Q^TAQ=\Lambda QTAQ=Λ

含义：

在某个正交特征向量坐标系下是纯伸缩 \boxed{ \text{在某个正交特征向量坐标系下是纯伸缩} } 在某个正交特征向量坐标系下是纯伸缩​

区别：

类型 公式 坐标系
一般可对角化矩阵 P−1AP=DP^{-1}AP=DP−1AP=D 可能是斜坐标系
实对称矩阵 QTAQ=ΛQ^TAQ=\LambdaQTAQ=Λ 正交坐标系

最核心的一句话

对角化就是找一组线性无关特征向量作为新坐标系 \boxed{ \text{对角化就是找一组线性无关特征向量作为新坐标系} } 对角化就是找一组线性无关特征向量作为新坐标系​

一般矩阵：

P−1AP=D P^{-1}AP=D P−1AP=D

实对称矩阵：

QTAQ=Λ Q^TAQ=\Lambda QTAQ=Λ

因为实对称矩阵的特征向量可以选成单位正交，所以 QQQ 是正交矩阵，满足：

Q−1=QT Q^{-1}=Q^T Q−1=QT
